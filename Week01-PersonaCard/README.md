# 项目：个人名片小程序

## 实现功能

1. 展示姓名、学号、个人照片
2. 个人自我介绍文字展示

## 运行方式

用 Visual Studio 打开 .sln 文件，按 F5 调试；在 [release](https://github.com/zaochih/univ-dotnet-assignments/releases/tag/Persona%400.0.1) 下载可执行文件。

需要安装 .NET 8 Desktop 运行时。
